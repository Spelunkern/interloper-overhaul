## External artwork

No wiki artwork is bundled in this documentation update. Requests to wiki pages,
the image-info API, and the tested wiki image CDN returned access errors in the
editing environment, so image provenance and a reliable downloadable file could
not be verified. The repository uses local diagrams rather than unverified remote
image embeds.

For future wiki illustrations, record the original file page, author/uploader,
rights holder, applicable reuse terms, retrieval date, and local filename before
adding the asset. A wiki page's general text license must not be assumed to cover
game artwork or every user-uploaded image. Credit Hinterland for its game art, and
keep any distinct uploader/photographer attribution and license required by the
specific file. Source links alone do not establish reuse rights.

Use small, relevant illustrations beside the systems they explain. Do not import
wiki articles, unrelated galleries, game bundles, or images whose source cannot be
identified. No external image should be represented as an in-game capture of this
mod unless it actually shows the mod's behavior.
